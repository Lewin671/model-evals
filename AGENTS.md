# Working on this benchmark

Use Python standard library only. Never publish credentials, raw CLI transcripts,
session IDs, home paths or personal configuration. Results must distinguish model
failures from infrastructure failures. Freeze generators and graders before paid
runs; never tune a grader to favor a model. Keep prompts identical across models.
Do not claim statistical significance from one small paired run.

English is the default language for the README, documentation and public reports.
Present this as model capability evaluation; Command Code and Codex are harnesses.
Every comparison must include model ID, harness, explicit reasoning effort and
whether identity/effort were observed or only configured. Publish measured results
with per-task evidence; never put illustrative scores in a real leaderboard.
